Gracias por tu tiempo,
Martín Rodríguez
hacecuentas.com
```

```

Martín — hacecuentas.com

**Reglas de outreach (para no quemar dominios):**
- Una nota por sitio, personalizada. Nada de copy-paste idéntico a 10 blogs.
- Mencioná SIEMPRE una nota real de ese blog (demostrás que lo leíste).
- Ofrecé valor primero (artículo original / recurso útil), el link es consecuencia.
- No mandes 10 pitches el mismo día desde la misma casilla. Tandalos.
- Si piden contraprestación económica explícita ("posicionamos tu link por X USD") → es link pago, evaluá aparte y con cuidado (riesgo Google).

## 4. Guía de anchor text para hacecuentas

El perfil de anchors tiene que parecer **natural**. Un sitio joven que de golpe acumula links con anchor exact-match ("calculadora de sueldo neto") es el patrón #1 que Google asocia a link building manipulativo → penalización por over-optimization (Penguin / spam de links). La defensa es un perfil **dominado por marca y genéricos**, con exact-match casi residual.

### Distribución objetivo

| Tipo de anchor | % objetivo | Ejemplos |
|----------------|-----------|----------|
| **Branded** | **~70%** | `Hacé Cuentas`, `Hacecuentas`, `hacecuentas.com`, `el sitio Hacé Cuentas` |
| **Naked URL** | ~10% | `hacecuentas.com`, `https://hacecuentas.com/sueldo-en-mano-argentina` |
| **Genérico / contextual** | ~12% | `esta calculadora`, `calcular acá`, `hacé el número acá`, `esta herramienta`, `mirá acá`, `lo podés calcular gratis` |
| **Parcial / temático** (NO exact) | ~5% | `calculadora de Hacé Cuentas`, `una calculadora de sueldos`, `herramienta para calcular el aguinaldo` |
| **Exact-match** | **~1-5% (máximo)** | `calculadora de sueldo neto`, `calculadora de aguinaldo`, `calculadora de monotributo` |

### Por qué esta distribución

1. **Branded domina porque es lo que pasa de verdad.** Cuando alguien te enlaza de forma orgánica, lo natural es nombrarte por tu marca o pegar la URL, no escribir el keyword exacto que vos querés rankear. Un perfil 70% branded le dice a Google "esto es una marca real que la gente cita", no "alguien está construyendo links".

2. **Genéricos y naked URL aportan diversidad sin riesgo.** "Calculá acá", "esta herramienta", la URL pelada — son anchors que ningún algoritmo penaliza porque no intentan forzar una keyword.

3. **Exact-match es el más poderoso PERO el más peligroso.** Un poco ayuda al ranking del término; demasiado es la huella clásica de manipulación. Con tu situación (dominio sin autoridad off-page, arrancando de cero) **mantené exact-match en 1-5% real** y reservalo para los links de mayor calidad y contexto (un guest post temático donde el anchor cae natural en la frase). Nunca uses exact-match en links masivos, de baja calidad o de directorios.

4. **Variá incluso dentro de cada categoría.** No uses siempre "Hacé Cuentas" idéntico: alterná con "Hacecuentas", "el sitio", la URL. La monotonía también es señal.

### Reglas prácticas

- **Primer link de cada dominio nuevo → branded o naked URL.** Nunca estrenes una relación con un anchor exact-match.
- En **guest posts** (donde controlás el texto): branded o genérico contextual. A lo sumo UN exact-match parcial si la frase lo pide naturalmente.
- En **niche edits**: dejá que el editor elija, o sugerí branded/genérico. No impongas exact-match.
- **Anchor del autor/bio**: branded o naked URL siempre.
- Llevá un **registro** (planilla) de cada link conseguido con su anchor y tipo, para no pasarte de exact-match sin darte cuenta. El % se mide sobre el total acumulado, no por link.
