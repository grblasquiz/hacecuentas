# Guest posting — targets vetados para hacecuentas

> ⚠️ Realidad 2026: el guest posting MASIVO en sitios "write for us" está **devaluado por Google**
> (lo trata como link comprado). Lo que SÍ suma es guest posting **editorial en sitios relevantes
> con audiencia real** (finanzas/contable/emprendedores LATAM). Calidad y relevancia >>> cantidad.
> Esto es un lever MENOR comparado con lo que ya tenés (dev.to DR90, GitHub Pages DR96 posteando
> solos). Hacelo selectivo, no a escala.

## Cómo funciona (no es automatizable)
Yo encuentro el target + redacto el pitch y el artículo; **vos mandás el mail** (el editor aprueba).
No hay forma de automatizarlo (requiere relación editorial). Flujo: pitch corto → si aceptan,
escribo el artículo (con 1 link contextual a una página-dato de hacecuentas) → ellos publican.

## ⛔ EVITAR (link farms / paid networks — Google las descuenta o penaliza)
- **badassbacklinks.com "255 finance guest post sites"** = lista para comprar links.
- **collaborator.pro / catalog** = marketplace de guest posts pagos (42k sitios).
- Cualquier sitio cuyo único contenido es "write for us" + posts de invitados sin audiencia.
- guangsuan / blucactus / agencias que "venden" guest post.

Regla: si el sitio existe **para vender** guest posts → no sirve (huella de link comprado).
Si el sitio tiene audiencia real y *además* acepta colaboraciones → sirve.
