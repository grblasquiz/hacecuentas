# Plan de backlinks para Bing/Yahoo (objetivo: 8x clicks orgánicos)

> Bing pondera links 2-3x más que Google. Cada link de calidad mueve la aguja más rápido en Bing que en Google.

## Tier 1 — Directorios de calculadoras (anchor: variantes "Calculadora X")

Submit gratis. Bing/Yahoo crawlean estos sitios activamente. Backlinks contextuales con autoridad.

| Directorio | URL | País | Notas |
|---|---|---|---|
| Calculator Soup | calculator-soup.com | US | Top global. Submit en /add-calculator |
| Online Calculator | online-calculator.com | UK | Lista de calcs por categoría |
| Calculadoras Online | calculadorasonline.com | ES | Español, alto tráfico |
| Calculatoria | calculatoria.com | LATAM | Permite submit con descripción |
| Calculadora.com.ar | calculadora.com.ar | AR | Verificar si acepta submissions |
| CalcuVio | calcuvio.com | ES | Categorías finanzas/cocina/salud |
| MiCalculadora | micalculadora.es | ES | Director de calcs |

**Acción**: por cada directorio, identificar 3-5 calcs hacecuentas top-relevantes a su categoría y enviar form/email con descripción + URL.

## Tier 3 — Blogs nicho con tráfico Bing/Yahoo

Bing skewse a usuarios 35+, Windows, profesionales. Estos blogs alinean:

- **PYME/contadores**: contadoresenred.com.ar, errepar.com (paywall pero buen perfil)
- **Salud**: vivilibresinglutencel.com, drlepetit.com.ar, omint.com.ar/blog
- **Inmobiliario**: argenproperties.com, zonaprop.com.ar/noticias
- **Educación**: educar.gov.ar, redined.educacion.gob.ar (ES)
- **Cocina argentina**: comerricoesfacil.com, recetario.com.ar

## Tier 4 — Universidades + .gov.ar (gold para Bing)

Bing ama backlinks .edu/.gov. Cada uno vale como 10 de blog.

- **Universidades públicas**: agregar calc a guías de estudiantes (impuestos, becas, cuotas)
  - UBA: Centro de estudiantes, sitios de facultades
  - UTN: cálculos técnicos (eléctrico, construcción)
  - UNLP: secciones de cátedras
- **Sitios .gov.ar**: difícil pero posible vía contenido educativo:
  - argentina.gob.ar/secciones (sugerir como recurso)
  - afip.gob.ar (improbable directo, pero a través de contadores que usen calc en notas)

## Tier 5 — Wikipedia + Wikidata (esto SÍ funciona en Bing/Copilot)

Bing/Copilot consulta Wikidata para contexto. Si hacecuentas figura como external link en Wikipedia ES, gana visibility tanto en Bing search como en AI responses.

- **Páginas Wikipedia relevantes** (ES):
  - es.wikipedia.org/wiki/Aguinaldo
  - es.wikipedia.org/wiki/Sueldo_anual_complementario
  - es.wikipedia.org/wiki/Monotributo
  - es.wikipedia.org/wiki/IIBB → Ingresos Brutos
  - es.wikipedia.org/wiki/Impuesto_a_los_Bienes_Personales
  - es.wikipedia.org/wiki/IVA
- **Estrategia**: agregar como external link al final, formato "Calculadora: Hacé Cuentas – [Calc específica]". Wikipedia revisa, si la calc es útil + sin paywall = permanece.
- **RIESGO**: si parece spam (link a home, no contextual), te revierten + flag.


## Tracking

Después de cada link conseguido:

1. Submit URL del artículo a Bing IndexNow para que crawl rápido
2. Anotar en `docs/backlinks-tracker.md` (fecha, sitio, calc linkeada, anchor)
3. Revisar BWT > Backlinks 4-6 semanas después para confirmar que Bing lo registró
